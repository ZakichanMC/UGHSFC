# UGHSFC

THIS PROJECT IS ARCHIVED.

First of all, if you're wondering what the title means, that's for me to know and you to never find out :)

The flaws in the idea of this game only revealed themselves after implementing and testing the base features. It simply wasn't fun. Devastated, I took a short break that turned from one day to one week and one month and now I don't think I'll ever return to it. Or maybe I will, one day.

But it's archived for now. While I may have left the project behind, I won't leave behind the lesson I learned. Work fast, work messy, and don't be afraid to iterate. Don't jump ship at the first sign of difficulty, you fool.

Thanks for reading, and happy gamedev-ing.
